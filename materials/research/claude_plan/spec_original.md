## 3. 符号与数据

**图与时间**
- 节点集 `V`(站点、终点站、场站),`|V| = m`,编号 1..m。
- 空驶时间矩阵 `τ(a,b)`(分钟),空驶距离矩阵 `w(a,b)`(km),`τ(a,a)=0, w(a,a)=0`。

**班次(trip)**,编号 i = 1..n,每个班次:
- 线路 `r_i`,起点 `o_i`,终点 `δ_i`,发车时间 `s_i`,到站时间 `e_i`,行驶里程 `d_i`(km),平均载客 `q_i`。
- 用的是一个**典型运营日**(例如工作日)的时刻表。若有工作日、周末多套时刻表,按最严格(车辆需求最大)的一天求解,或分别求解。

**车辆**
- `κ`:单车容量(座位加站位);`R`:最大续航;`T`:满电充电时间;`ρ`:安全余量(如 0.1);实际可用续航 `R' = (1−ρ)·R`。**以下公式中的 R 都指 R'。**

**充电站**
- 候选站点就是 `V` 中的节点。选中集合 `S ⊆ V`。

**从两个常数推出的物理量(用于 Q1、Q2)**
- 每 km 耗电 `ε`(kWh/km);电池可用容量 `B_use = ε·R`,标称容量 `B = B_use / u`(`u` 为可用深度,如 0.8)。
- 充电功率 `P = B_use / T`。这样 `R` 决定电池大小、电池成本和电池隐含碳,`T` 决定充电桩功率、桩成本和电网峰值负荷。

## 4. 核心问题 P1:运载能力等价的电车调度(充电站已给定)

### 4.1 输入

```
第 1 行:n m R T
第 2 行:c_1 … c_m              (c_v=1 表示站点 v 有充电站)
接下来 m 行:空驶时间矩阵 τ     (m×m)
接下来 m 行:空驶距离矩阵 w     (m×m)
接下来 n 行:o_i δ_i s_i e_i d_i
```

### 4.2 输出

```
第 1 行:最少车辆数 N
接下来 N 行:每辆车依次执行的班次编号(1 起),需要充电处写 C(v),表示在站点 v 充电
```

### 4.3 可行的单车行程

一辆车的行程是一个序列,由班次和 `C(v)` 记号交替组成。设车辆已完成班次 i,位于 `δ_i`,时刻 `e_i`,自上次满电起已行驶 `u_i` km。下一个班次 j 有两种接法:

**直接接**(中间没有 `C`):
```
e_i + τ(δ_i, o_j) ≤ s_j
u_i + w(δ_i, o_j) + d_j ≤ R
之后:u_j = u_i + w(δ_i, o_j) + d_j
```

**先充电再接**(中间有 `C(c)`,且 `c ∈ S`):
```
u_i + w(δ_i, c) ≤ R                         # 先要能开得到充电站
e_i + τ(δ_i, c) + T + τ(c, o_j) ≤ s_j      # 时间来得及
w(c, o_j) + d_j ≤ R                         # 充满后要能开到并跑完 j
之后:u_j = w(c, o_j) + d_j                  # 续航清零重计
```

**一辆车的第一个班次**:从该班次起点、满电开始,`u = d_first`,要求 `d_first ≤ R`。

**全局约束**:每个班次恰好出现在一辆车的行程中一次。

### 4.4 目标

最小化车辆数 `N`。次要目标(用于打破平局,可选):总空驶里程、总充电次数。

## 5. 增强问题 P2:选站加调度

### 5.1 输入

```
第 1 行:n m R T K
接下来 m 行:空驶时间矩阵 τ
接下来 m 行:空驶距离矩阵 w
接下来 n 行:o_i δ_i s_i e_i d_i
```
与 P1 相比:没有"哪些站有充电站"那一行,多了 K。

### 5.2 输出

```
第 1 行:选中的站点编号(最多 K 个,空格分隔;不建站时为空行)
第 2 行:最少车辆数 N
接下来 N 行:每辆车的班次序列,充电处写 C(v)
```

### 5.3 目标

在所有 `|S| ≤ K` 的选法里最小化 `N`。

**变体(连接 Q2 的成本模型)**:不限制 K,改为最小化 `N · c_bus + |S| · c_station`。

## 6. 柴油系统的运载能力表示,以及"不低于"的含义

**6.1 三个层面的运载能力**
1. 时间维度:在运营车辆数 `n(t) = |{i : s_i ≤ t < e_i}|`,高峰车辆需求 `PVR = max_t n(t)`。
2. 供给量:座位公里 `Cap = κ · Σ d_i`,每条线每时段的运力 `κ · F_{r,w}`(`F` 为该线该时段班次数)。
3. 需求满足:校验每个班次 `q_i ≤ α·κ`(`α` 为允许的最大满载率)。

**6.2 等价条件(已确定)**:电车方案**覆盖每个班次恰好一次,且准点**。此时 6.1 的三个指标自动与柴油系统相同。

若 `κ_e < κ_d`,把班次 i 复制 `m_i = ⌈κ_d / κ_e⌉` 份(同一时刻同一线路各发一辆),再套用上面的条件。

**6.3 柴油基准 `N_d`**:班次兼容图上,若 `e_i + τ(δ_i, o_j) ≤ s_j` 则连边 i→j。柴油车队规模 `N_d = n − 最大匹配数`(二分图最大匹配,Hopcroft–Karp)。这是忽略车场约束时的最小路径覆盖;有多个车场时是 NP-hard,用启发式。

**6.4 命题(写论文时可以给出简要证明)**
1. 任何 P1 可行解覆盖全部班次,所以与柴油系统运力相同。
2. `N_e ≥ N_d`:电车只是在柴油的约束上增加了续航和充电条件,可行域变小。
3. 当 `R = ∞` 时,直接连接永远满足续航约束,P1 退化为 6.3 的最小路径覆盖(`T` 和 `S` 不再起作用)。柴油系统就是这个特例。
4. 在块已固定的前提下,第 7 节第二层是精确的(DAG 上的顶点不交路径覆盖 = 顶点数 − 最大匹配)。
5. 一般情况的 EVSP 是 NP-hard(带续航约束的车辆调度),所以用启发式,并用 MILP 在小规模上做基准。

## 7. 算法

整体是**三层**:内层调度 `evaluate(S)`(两步:分块、连接),外层选站 `select_stations(K)`。

### Step 0 预处理
- 构造班次兼容关系 `e_i + τ(δ_i, o_j) ≤ s_j`。
- 计算 `N_d`、`PVR` 作为基准和下界。

### Step 1 第一层:分块(贪心 best-fit)

一个**续航块**是一串可以连续执行、总里程(含块内空驶)≤ R 的班次。

```
按 (s_i, e_i) 升序遍历班次 j:
    候选块 = { B | B 的末班次 ℓ 满足 e_ℓ + τ(δ_ℓ, o_j) ≤ s_j
                   且 dist(B) + w(δ_ℓ, o_j) + d_j ≤ R }
    key(B) = (1−α)·(R − 新里程)/R + α·空闲时间/时间跨度
    若候选非空:把 j 加入 key 最小的块
    否则:新开一个块(dist = d_j)
```
- `α=0`:装得最满(装箱的 best-fit);`α=1`:空闲时间最短(无续航约束时对区间划分最优);中间值折中。
- 参考实现先跑 `α ∈ {0, 1, 0.5}` 三次确定性运行,再做若干次随机 `α` 加噪声的重启。

### Step 2 第二层:连接块(二分图最大匹配)

每个块 b 有 `S_b`(首班次发车时间)、`E_b`(末班次到站时间)、起点、终点、总里程 `dist_b`。块 a 后面可以接块 b,当且仅当存在 `c ∈ S` 满足:
```
dist_a + w(end_a, c) ≤ R
E_a + τ(end_a, c) + T + τ(c, start_b) ≤ S_b
w(c, start_b) + dist_b ≤ R
```
对这个块图做二分图最大匹配,得到 `N = |B| − |M|`。匹配出的路径给出每辆车依次执行的块,块之间插入 `C(c)`(多个可行的 c 取总空驶 `w(end_a,c) + w(c,start_b)` 最小的)。

### Step 3 改进
- 随机重启:保留 `(N, −块图边数)` 字典序最小的解(边数多表示连接更灵活,用来打破 N 的平局)。
- **建议在论文版本中加入**:块之间的 relocate(移动一个班次)和 swap(交换班次)局部搜索,接受使 `(N, −边数)` 变小的改动;以及"充电感知的分块",见第 8 节的局限。

### Step 4 校验
每个班次恰好出现一次;每个块里程 ≤ R;每次充电前后的时间、里程条件成立;充电站 ∈ S。参考实现的 `validate()` 是独立于求解器的检查函数。

### Step 5 外层选站(P2)

```
candidates = 按 station_scores 排序的前 L 个站点
    station_scores[v] = 连续班次对 (i,j) 中,在 v 充电后时间仍来得及的对数
S = ∅
重复 K 次(贪心加点):
    选使 (N, −边数) 最小的 v 加入 S;若没有改进则停止
然后做交换改进:
    对每个 v ∈ S、u ∉ S,试 S − v + u,若 (N, −边数) 变小就接受,直到没有改进
```

### Step 6 小规模精确基准(MILP,用于论文里验证启发式质量)

变量:`x_a ∈ {0,1}`(弧 a 被使用)——包括车场出发弧、直接连接弧、经充电站 c 的连接弧、返回弧;`u_j ∈ [0,R]`(班次 j 结束时自上次满电起的里程);P2 再加 `y_c ∈ {0,1}`(是否建站)。

```
min  Σ_j z_{0j}                              (起点弧总数 = 车辆数)
     [P2 变体:+ λ · Σ_c y_c]
s.t. 每个班次入度 = 出度 = 1
     直接弧 (i→j):      u_j ≥ u_i + w(δ_i,o_j) + d_j − M1_ij · (1 − x_ij),   M1_ij = R + w(δ_i,o_j) + d_j
     充电弧 (i→j 经 c): u_j ≥ w(c,o_j) + d_j − M2_ijc · (1 − x_ijc),          M2_ijc = w(c,o_j) + d_j
                        u_i + w(δ_i,c) ≤ R + M3_ijc · (1 − x_ijc),            M3_ijc = w(δ_i,c)
     车场出发弧:        u_j ≥ d_j · z_0j
     u_j ≤ R
     [P2] x_ijc ≤ y_c;  Σ_c y_c ≤ K
```
(弧只在时间可行时才生成,所以时间约束隐含在弧集合里;`M` 取各弧自己的最小够大的常数,弧未被使用时约束恒成立。`u_j ≤ R` 同时保证 `w(c,o_j) + d_j ≤ R`。)

### 复杂度
- 第一层 `O(n·|B|)`;第二层建图 `O(|B|²·|S|)`,匹配 Hopcroft–Karp `O(E√|B|)`。
- 外层选站:`O(K·L·cost(evaluate))`。
- 参考实现用的是 Kuhn 匹配和 `O(n²)` 循环,n 到几千时请换 Hopcroft–Karp,并只考虑时间窗内的候选对(例如只看之后若干小时内的班次)。

### 可选扩展:每站桩数限制
每站 `p_c` 个桩时,同一时刻在站 c 充电的车数 ≤ `p_c`。第二层的匹配不再精确。做法:先按无限桩求解,再用扫描线检查各站占用,冲突的充电弧禁用后重新匹配,迭代到无冲突。

## 8. 参考实现与验证结果

`solver_reference.py` 包含:`build_blocks`、`link_blocks`、`evaluate`、`select_stations`、`validate`、`exact_min_buses`(穷举,仅 n≤9)。命令行用法:

```
python solver_reference.py p1 < input   # P1,充电站以 0/1 给定
python solver_reference.py p2 < input   # P2,选至多 K 个站
```

**已验证的结果**(以下数字来自对该文件的真实运行):

- **样例**(第 9 节):P1 输出 N=1;P2(K=1)选站点 2,N=1;K=0 时 N=2。穷举精确解与之一致。
- **随机小规模对照**:n=8 个班次,m=3 个节点,R=30,T=20,随机选 0–2 个站,共 300 个实例(种子 0–299)。生成方式:节点间 `τ` 取 5–20 的整数且对称,`w = round(0.7τ)`,发车时间取 0–160,行驶时间 = `τ + (0–5)`,里程 = `w + (0–3)`。
  - 300 个解全部通过独立校验,没有出现比精确最优更少的车(一致性检查通过)。
  - 启发式等于精确最优的实例数:不重启 203/300,30 次重启 212/300,300 次重启 214/300;**最大差距 2 辆**。
- **柴油极限**(R=10⁹,T=0):200/200 个实例与精确解相同。
- **P2 选站**(m=4,K=2,60 个实例):选站结果等于穷举所有站点子集后的最优 N 的有 42/60。

**局限(必须在论文里如实写出)**
- 在小规模随机数据上,启发式有大约三成实例比精确最优多 1–2 辆车,而且不建站(S=∅)时也存在差距(105 个中 79 个最优),说明主要问题在第一层的贪心:**分块不知道哪里可以充电**,并且只做一次性的贪心装箱。增加随机重启只能小幅改善。
- 因此论文版本应该:(a) 加入局部搜索或充电感知的分块;(b) 在小规模上用 MILP 给出最优解,量化差距;(c) 报告大规模下启发式相对于下界(`max(N_d, PVR)`、MILP 的 LP 松弛)的差距。
- 如果有时间,更强的方案是**集合划分加列生成**:主问题是"每个班次恰好被一条车辆行程覆盖"的集合划分,定价子问题是带资源(自上次满电的里程)约束的最短路,可以在按时间排序的 DAG 上用标号法求解。

## 9. 样例

数据:2 个站点,`τ = [[0,15],[15,0]]`,`w = [[0,10],[10,0]]`,R=30,T=20。六个班次(站点 1 与 2 之间往返,每趟 10 km):

| 班次 | 起点→终点 | 发车 | 到站 | 里程 |
|---|---|---|---|---|
| 1 | 1→2 | 0 | 15 | 10 |
| 2 | 2→1 | 20 | 35 | 10 |
| 3 | 1→2 | 40 | 55 | 10 |
| 4 | 2→1 | 80 | 95 | 10 |
| 5 | 1→2 | 100 | 115 | 10 |
| 6 | 2→1 | 120 | 135 | 10 |

**P1 样例输入**(两个站点都有充电站):
```
6 2 30 20
1 1
0 15
15 0
0 10
10 0
1 2 0 15 10
2 1 20 35 10
1 2 40 55 10
2 1 80 95 10
1 2 100 115 10
2 1 120 135 10
```
**输出**(已运行验证):
```
1
1 2 3 C(2) 4 5 6
```
**解释**:班次 1、2、3 共 30 km,正好用完 R;3 号在 55 分到站点 2,在站点 2 充电到 75 分,赶得上 80 分发车的 4 号。所以一辆车就够。

**P2 样例输入**(K=1):
```
6 2 30 20 1
0 15
15 0
0 10
10 0
1 2 0 15 10
2 1 20 35 10
1 2 40 55 10
2 1 80 95 10
1 2 100 115 10
2 1 120 135 10
```
**输出**(已运行验证):
```
2
1
1 2 3 C(2) 4 5 6
```
**对照**:
- K=0(不建站):N=2,方案为 `1 2 3` 和 `4 5 6`。
- 只选站点 1:N=2(穷举验证)。1 辆车跑完 1、2、3 后已用满 30 km,开不到站点 1;而 2 号班次 35 分到站点 1,充电要到 55 分,赶不上 40 分发车的 3 号。
- 选站点 2:N=1。**选哪个站决定答案**,这就是 P2 要解决的问题。
- 把 4 号班次改成 70 发车、85 到站:站点 2 的空档只有 15 分钟,小于 T=20,充不了电,不论选哪个站 N 都是 2。

## 10. 从调度输出到论文四问

调度模块(第 4–7 节)对每个城市输出:`N_d`、`PVR`、`N_e`、选中的站点集 `S`、每辆车的行程、总服务里程 `D_serv`、总空驶里程 `D_dh`、每日充电次数、每日充电总电量。下面是**建议**的下游模型,请按你手上的数据调整。

### Q1 生态模型(建议)

**年排放变化**
```
ΔE_t = E_diesel − E_electric
E_diesel   = D_diesel · (EF_tailpipe + EF_upstream)             # 柴油:尾气加燃料上游,gCO2e/km
E_electric = (D_serv + D_dh) · (ε/η) · γ_t  +  E_battery,annual # 电:耗电×电网碳强度 γ_t
E_battery,annual = B · e_batt / L_batt                           # 电池隐含碳摊销
```
- `ε` 每 km 耗电,`η` 充电效率,`γ_t` 第 t 年电网碳强度(随电网脱碳下降,单独给情景),`e_batt` 单位容量电池隐含碳(kg CO2e/kWh),`L_batt` 电池寿命。
- `B = ε·R/u`:**续航 R 决定电池大小**,所以 R 越大电池隐含碳越高——这是两个常数模型里 R 的生态含义。
- **当地污染物**:尾气 NOx、PM2.5 的削减量 = 柴油里程 × 排放因子(电车尾气为零),可选用社会成本系数折算健康效益。
- **碳回收期**:电池隐含碳多少年被运营减排抵消。
- **噪声、能源安全**等可作定性补充。
- 必须计入调度模块给出的**额外里程**:`D_dh` 和因 `N_e > N_d` 增加的车辆。

输出:年度和累计的 CO2e、NOx、PM2.5 变化;对 `γ_t` 情景、`ε`、`R` 的敏感性。

### Q2 财务模型(建议)

**成本项**(以转换为单位计算,折现率 `r`)
```
CAPEX = N_e · (c_bus_body + c_batt · B)         # 车体加电池
      + Σ_{v∈S} c_station(P, 桩数)               # 充电站,P = B_use/T
      + c_grid_upgrade                           # 电网接入/配电升级
      − 回收的柴油车残值
OPEX_t = 电价·耗电量 + 电车维保·里程 + 电池更换(寿命到期那年) + 充电站维保
对照基准(继续用柴油):N_d 辆柴油车的购置/更新、柴油费、柴油车维保
```
**外部资金**:补助比例 `φ ∈ [0, 0.5]`,覆盖转换成本(建议定义为"电车及充电基础设施的增量转换成本")的 `φ`:
```
自筹 CAPEX = (1 − φ) · CAPEX_transition
```
**指标**:`NPV(转换) = NPV(基准继续柴油的成本) − NPV(转换成本)`、全生命周期成本每车公里(TCO per vehicle-km)、回收期、**使 NPV=0 所需的最低补助比例 φ\***;对 `φ = 0, 0.25, 0.5` 分别报告。

**敏感性**:电价、柴油价、电池价格(随时间下降 `c_batt(t)=c_batt,0·(1−δ)^t`)、折现率、车辆寿命、`R`、`T`、`K`。

**P2 成本变体**:`min N·c_bus + |S|·c_station`,画 **N(K) 曲线**,找拐点作为推荐站点数。

### Q3 十年路线图(建议)

时间 `y = 1..10`(2024–2033)。把线路集合 `𝓡` 逐步电动化:选嵌套的线路集合 `E_1 ⊆ E_2 ⊆ … ⊆ E_10 = 𝓡` 和嵌套的站点集 `S_1 ⊆ … ⊆ S_10`。

- 第 y 年:对 `E_y` 内线路的班次运行调度模块,得 `N_e(E_y)` 和 `S_y`;其余线路仍由柴油车运行,用匹配求 `N_d(𝓡∖E_y)`。
- 当年新购电车数 = `N_e(E_y) − N_e(E_{y−1})`;柴油车按车龄退役(**优先退役老车**,避免提前报废)。
- 约束:每年预算(自筹加补助,补助 ≤ 转换成本的 50%),第 10 年末全部电动。
- 目标:最小化总成本现值,或在预算内最大化累计减排;可用加权的多目标。
- **线路排序启发式**:对每条线路 r 打分
  `score_r = 年减排量 / 增量成本 × 续航适配度`,
  其中续航适配度用 `N_e^r / N_d^r`(单线路单独求解的车辆比,越接近 1 越适合先转)、该线路平均块长相对 R 的比例、该线路柴油车平均车龄等衡量。按分数从高到低排,受每年预算约束。
- 采购时机:电池价格下降意味着**能晚买的尽量晚买**,与"早转早减排"权衡。
- 输出:逐年的线路清单、电车数、新增站点、投资额和补助、累计排放、现金流。

对**三个都市圈**使用同一流程,比较结果(如 `N_e/N_d`、总投资、回收期),并说明为什么不同城市的最优顺序不同。

### Q4 一页信(建议结构)
致某城市交通官员:一句话推荐;三个关键数字(需要多少辆电车、多少充电站、需要多少补助);时间表(三个阶段);预期的减排和财务结果;主要风险和缓解(冬季续航下降、电网容量、补助不确定);下一步行动。一页,语气面向非技术读者。

## 13. 必须在论文里说明的假设与局限

1. 续航 R 和充电时间 T 是常数,不随温度、载重、电池衰减、空调使用变化(用安全余量 ρ 和对 R 的敏感性分析来覆盖)。
2. 充电一次花 T 分钟并充满;不考虑部分充电(可选扩展:线性部分充电,时间 = T·所需电量/满电量)。
3. 默认不限制每站充电桩数、不考虑电网容量限制(可选扩展见第 7 节末)。
4. 默认不考虑车场出入库空驶;若要考虑,把"从车场到首班次起点"和"从末班次终点回车场"的距离计入续航约束。
5. 使用典型运营日的时刻表;周末和节假日需分别检验。
6. 电车与柴油车座位数相同(否则班次复制)。
7. 启发式不保证最优,已用小规模穷举和 MILP 对照并报告差距(第 8 节)。
8. 载客量 `q_i` 只用于校验容量,不进入调度的决策。
