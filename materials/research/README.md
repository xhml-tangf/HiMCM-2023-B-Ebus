# 研究记录索引

本目录是项目的外部证据和整理材料，与可直接运行的模型代码分开保存。

- `claude_plan/`: 用户提供的规划、参考程序、三城时刻表取得说明、引用核验和 AI 披露清单。原始 Claude 完整对话仍未提供。
- `evidence_audit_v2/`: 证据主表、数据资产清单、缺口登记、来源索引、历史版本回收和研究问题支持矩阵。
- `himcm_exemplars/`: COMAP 结果链接、公开获奖论文和仅用于版式的调研记录。这里的 PDF 不是本项目的模型输入。
- `data/processed/`: 公开证据审计产生的结构化记录；与模型运行所需的 `data/processed/` 分开。
- 其余顶层 Markdown：参数台账、方法边界、文献、评审处理、数据申请和结果说明。

证据与假设的区分以证据主表和论文正文中的边界说明为准。模型输出即使写入 `results/`，也不自动成为独立事实证据。

大体积原始文件按根目录 `materials/README.md` 的说明从 GitHub Release 恢复。
